# CGPA, Percentage & GPA Converter

A free, single-file web tool that converts CGPA, percentage and 4.0 GPA (CBSE, VTU and Mumbai University formulas included). No build step, no dependencies.

Live: https://spacehubglobal.github.io/cgpa-percentage-gpa-converter/

## Run locally
Open `index.html` in a browser.

## Notes
Results are estimates. Universities and credential evaluators may convert grades differently, so rely on official transcripts for admissions and visas.
